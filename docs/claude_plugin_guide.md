# 🟣 TransactAI — Official Anthropic Claude Integration Guide

Connect **TransactAI** to **Anthropic Claude Desktop** and **Claude.ai** via the Model Context Protocol (MCP). Claude handles conversational reasoning, product comparison, and user decision-making, while **TransactAI acts as the trusted execution engine** that validates merchant stock, enforces spending guardrails, and generates Razorpay checkout links.

> **Core Principle:**  
> *"AI decides. TransactAI transacts. Claude helps users decide what to buy; TransactAI validates, verifies, and executes the purchase."*

---

## 💻 Option A: Local Laptop (Claude Desktop App via stdio)

Use this method to run TransactAI natively inside Claude Desktop on your computer:

### Step 1: Open Configuration File
On Windows:
```text
Win + R → %APPDATA%\Claude\claude_desktop_config.json
```
On macOS:
```text
~/Library/Application Support/Claude/claude_desktop_config.json
```

### Step 2: Paste the TransactAI MCP Server Config
```json
{
  "mcpServers": {
    "transactai": {
      "command": "C:\\Users\\ASUS\\Desktop\\resume project\\Razorpay\\razorpay\\python.exe",
      "args": [
        "-m",
        "app.mcp.server"
      ],
      "cwd": "C:\\Users\\ASUS\\Desktop\\resume project\\Razorpay",
      "env": {
        "TRANSACTAI_BASE_URL": "https://frontend-six-steel-85.vercel.app"
      }
    }
  }
}
```

> **Note:** `TRANSACTAI_BASE_URL` points to your live hosted Vercel frontend (`https://frontend-six-steel-85.vercel.app`), ensuring payment links generated by Claude open your modern Next.js checkout page directly.

### Step 3: Restart Claude Desktop 🎉
1. Completely quit Claude Desktop (check the system tray) and reopen it.
2. Look for the **🔨 Hammer / Tools icon** in the prompt box showing active TransactAI tools:
   - `transact_search_catalog`
   - `transact_check_policy`
   - `transact_create_order_payment`
   - `transact_verify_order_preflight`
   - `transact_register_merchant`

## ☁️ Option B: Remote Cloud Connector (Claude.ai Web & Desktop)

Connect directly to the live Railway production MCP server with zero local environment setup:

### Step 1: Open Connectors in Claude
1. Open [Claude.ai](https://claude.ai) in your browser or launch Claude Desktop.
2. Click your user avatar in the bottom-left corner ➔ **Settings** ➔ Navigate to **Connectors** (or **Feature Previews / Integrations**).
3. Click **"Add Custom Connector"**.

### Step 2: Enter TransactAI Production Details
- **Connector Name**: `TransactAI Autonomous Commerce`
- **Connector URL**: `https://transact-ai-production.up.railway.app/mcp`
- *(Optional Fallback SSE)*: `https://transact-ai-production.up.railway.app/mcp/sse`

### Step 3: Click Add & Verify Active Tools
Click **Add**. Claude establishes an active SSE stream and immediately registers the 5 commerce tools (look for the **🔨 Hammer Icon**):
- `transact_search_catalog`
- `transact_verify_order_preflight`
- `transact_check_policy`
- `transact_create_order_payment`
- `transact_register_merchant`

### Step 4: Test Autonomous Shopping in Natural Language
Start a new chat with Claude and ask:
> *"Search for fresh Kaju Katli in Indiranagar (pincode 560001) under ₹600. Check my daily spending limit, and if approved, prepare an order summary for my confirmation."*

## 🧠 3. Recommended Claude Operating Instructions

When creating a Project or setting Custom Instructions in Claude, paste:

```text
You have access to TransactAI via Model Context Protocol (MCP). Follow this progressive disclosure protocol:

PROGRESSIVE SHOPPING PROTOCOL:
1. Discovery (Broad Intent):
   - If user asks generally (e.g. "I want sweets"), call 'transact_search_catalog(query="sweets")' and display popular options. Do NOT ask for address or pincode yet.
2. Selection & Location Gathering:
   - When user picks an item, warmly confirm and ask for delivery address and 6-digit pincode to locate the nearest fulfillment store.
3. Pre-flight & Contact Gate:
   - Run 'transact_verify_order_preflight' to verify live stock and buyer limits.
   - Present the Order Summary Card (Product, Merchant, Address, Total ₹).
   - Ask for Phone Number (for delivery rider coordination if delivery, or store pickup SMS alerts if pickup) and final confirmation.
4. Trusted Checkout:
   - On explicit confirmation with phone, run 'transact_create_order_payment' with address, pincode, and phone.
   - Provide the official Razorpay hosted checkout URL: https://frontend-six-steel-85.vercel.app/pay/{order_id}.
```
